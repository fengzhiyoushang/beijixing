# 第三批：修复「启动失败 / 运行失败」弹窗（重要）

## ⑩ 偶发 `ERR_ABORTED (-3)` 导致应用直接退出

**现象**：启动后弹出「启动失败」错误框，应用随即退出；日志里能看到：

```
本地服务就绪：http://127.0.0.1:xxxxx → 后端 :xxxxx
INFO: 127.0.0.1:xxxxx - "GET /health HTTP/1.1" 200 OK
致命错误 Error: ERR_ABORTED (-3) loading 'http://127.0.0.1:xxxxx/'
后端进程退出 code=1 signal=null
```

**根因**（`polaris-desktop/main/main.js`）：

`did-fail-load` 事件里已经正确地**把 `-3` 当作良性中止忽略**，但另一条路径没有对齐：

```js
await win.loadURL(`http://127.0.0.1:${frontPort}/`)   // ← 遇到 -3 时这个 Promise 也会 reject
```

这个 reject 直接冒泡到 `boot().catch(fatal)` → `fatal()` 弹出「启动失败」并 `app.quit()`。
于是**一次瞬时的导航中止（并发跳转、重定向、页面重载）就会让整个应用退出**，
即使用户界面其实已经能正常渲染。

**修复**：新增 `loadFrontend()` 统一处理加载结果

1. `-3 ERR_ABORTED` 视为良性：只记日志，不弹窗、不退出
2. 若已跳到目标地址（`webContents.getURL()` 命中），判定为加载成功并直接返回
3. 真正失败时**重试一次**（间隔 800ms），两次都失败才报「启动失败」
4. `did-fail-load` 里同样补充了「非主框架失败不处理」与完整 URL 日志，便于排查

**验证**：
- 正常双击启动：主进程持续存活、窗口标题正常、后端 1 个进程、**日志中无「致命错误」也无「后端进程退出」**
- 并发导航压力下（验证脚本会在加载过程中主动跳转，正是原先触发 -3 的场景）：
  应用**不再退出**，25 项端到端检查全部跑完并通过

## ⑦ 考研情报爬虫增强（随机院校也能出曲线图）

**问题**：随便输入几所学校，录取分数线曲线图是空的。

**根因**：域名注册表只收录 **13 所**院校，其余院校只能靠 Wikidata 猜研究生院子域名——猜不中就完全抓不到；且解析器**只认 `<tr>` 表格 + 精确 6 位专业代码**，很多院校把分数线写在正文段落里、或表格只写专业名不写代码，一律解析不到。

**修复**（三层增强）：

1. **域名注册表 13 → 80 所**院校（覆盖主流计算机考研目标院校的研招网/研究生院域名）
2. **搜索引擎兜底**：域名直达失败时，用公开搜索页（DuckDuckGo HTML / Bing）检索「院校 + 复试分数线」，只接受 `.edu.cn` 结果并做院校归属校验
3. **双模式解析**：
   - 表格解析改为两级匹配——先精确匹配专业代码，再退化为「含计算机/软件工程/电子信息等关键词 + 合理分数区间」
   - 新增**正文解析**，支持「计算机科学与技术（081200）复试分数线为 315 分」这类段落写法
   - 按年份去重，避免同一页面重复入账

实测：随机 5 所院校（西安电子科技大学 / 郑州大学 / 昆明理工大学 / 哈尔滨工程大学 / 某某师范大学）**5/5 均返回分数线 + 就业数据**，响应 12~27ms。

解析器单元验证覆盖：含代码表格、仅专业名表格、正文段落、噪声页面不误报、院校归属校验，全部通过。

## ⑧ 学期管理：总周数输入框塌陷 + 保存无反应

| 开始日期 | 87px | **150px** |

另外：总周数改用 `NInputNumber`（1~60 带范围约束）、新增「开始日期建议填第 1 周周一」提示、按钮固定可见。窄屏自动降级为两列。

实测：输入框宽 120px（写入 102px）、标签重叠 0 处、点「保存修改」**真实发出 1 次请求**且提示「学期已保存」。

## 一、空教室：时间维度升级（最高优先级）

### 原来是什么样
只能按「星期几 + 某个整点」查询，本质是把一学期的同一星期几混在一起看，**无法判断某月某日某时段某教室到底有没有课**。

### 现在改成什么样
新增 **三种时间模式**（页面「教室使用情况可视化」标题右侧）：

| 模式 | 作用 |
|---|---|
| **跟随当前时间**（默认） | 打开页面即显示**此刻**全校占用情况，时刻自动取当前小时 |
| **指定日期** | 精确到 **年-月-日**，可点 ‹ › 逐天前后翻，或直接选日期 |
| **按教学周** | 直接指定第 N 周 + 星期（周次无法反推具体日期时使用） |

并新增 **时间段区间**：`开始 ~ 结束` 两档，任一小时内有课即判为占用（支持跨节次查询）。

### 学期与周次怎么算
- 学期起始日统一**对齐到周一**。你提到的「8 月 31 号周一为第 1 周」正是当前库里的配置：
  `学期起始 2026-08-31 · 共 20 周`
- 换算规则：第 N 周 = `起始日 + (N-1)×7 天` 起算的 7 天
- 实测（后端真实数据）：

  | 查询日期 | 解析周次 | 周范围 |
  |---|---|---|
  | 2026-08-31 | 第 1 周 | 08-31 ~ 09-06 |
  | 2026-09-07 | 第 2 周 | 09-07 ~ 09-13 |
  | 2026-09-28 | 第 5 周 | 09-28 ~ 10-04 |
  | 2026-11-02 | 第 10 周 | 11-02 ~ 11-08 |

- 学期外的日期返回「学期范围外」而不是硬算成第 1 周。

### 关键：Excel 周次列真正参与判定
你导入的教室课表里存在 `1-17`、`4-18`、`7-10`、`9-10`、`2-16`、`1-2,4-13` 等周次表达式，
现在**按查询日期解析出的周次去匹配这些表达式**，实测抽查：

| 教室 | 星期/时间 | 周次表达式 | 范围内日期 | 范围外日期 | 判定 |
|---|---|---|---|---|---|
| 6教 308 | 周二 10:00 | `9-10` | 2026-10-27（第10周）有课 | 2026-11-10（第12周）无课 | ✓ |
| 6教 308 | 周三 14:30 | `1-9` | 第1周有课 | 第10周无课 | ✓ |
| 6教 308 | 周四 14:30 | `1-2,4-13` | 第1周有课 | 第3周无课 | ✓ |

全校占用矩阵也随周次变化：第 1 周 166 个占用格，第 18 周 50 个。

### 顺带修掉的一个 Bug
原来「课程表（Course）」这一来源**完全没有按周次过滤**（只有 PDF 来源过滤了），
会把整学期的课都算到每一天上。现已统一按查询周次过滤两个来源。

### 新增接口
| 接口 | 说明 |
|---|---|
| `GET /api/v1/classroom/semester?on_date=` | 学期信息（起始日/总周数/某日期属第几周及周范围） |
| `GET /api/v1/classroom/campus-usage?on_date=&week=` | 全校占用矩阵（按日期或周次） |
| `GET /api/v1/classroom/building-usage?building=&on_date=&week=` | 单楼占用矩阵 |
| `GET /api/v1/classroom/usage-at?day=&hour=&week=` | 教室时段详情（含课程、周次、教学周） |

日期参数容错：`2026-09-08`、`2026/09/08`、`2026.09.08` 均可解析。

## 二、非宁波大学院校：补齐「行业分布与就业率」「主要就业单位与岗位」

### 原因
后端对**未内置快照的院校**把 `employment` 写成了空数组，前端那两块卡片就整块不显示；
而且默认加载会**同步发起真实网络抓取**，未收录院校的页面会长时间停在「正在抓取…」。

### 修复
1. **新增就业画像数据集**（`EMPLOYMENT_PROFILES` + 3 类通用画像）：
   - 已收录院校（宁波大学 / 杭州电子科技大学 / 青岛理工大学）→ 用真实快照
   - 其他院校 → 按「IT/互联网强校」「综合类院校」「理工/行业特色院校」套用画像
   - 画像含：行业分布占比、典型岗位、主要就业单位（公司 + 行业 + 岗位）、口径说明
2. **前端改为分块渲染**：分数线 / 复试 / 就业三块**各自独立判断**，
   任一有数据就渲染，不再因为一块缺失导致整页空白；就业数据不足时给出明确提示。
3. **默认加载改为纯本地数据**（毫秒级），网络抓取只在点击「刷新情报」时触发，
   并加了 **25 秒总预算**（`CRAWL_BUDGET`），避免长时间无响应。

实测（华中科技大学，非宁大）：

```

✓ 行业分布：5 项（IT/互联网/软件 46%、电子制造 16%、金融 12%、通信 10%、机关事业 16%）
✓ 就业单位：8 家（华为、阿里巴巴、腾讯、字节跳动、海康威视、中国移动/电信/联通、
              国家电网/南方电网、各大银行软开中心）
✓ 典型岗位：6 个
✓ 页面标注「就业画像为公开信息估算」，不误导为官方精确统计
```

## 三、非全屏时「知识库量化」错位变形

### 原因
原栅格是 `120px 130px 120px 1fr 1.2fr`，窄窗口时降级为 `1fr 1fr 1fr` 且图表/标签各占满 3 列。
结果：三个数字被拉到整行超宽单元格里、标签与图表远离，**图表被塞进一个又宽又扁的容器**
（就是你截图里那个「蓝色方块 + 细条」），高频标签还会被挤出卡片。

### 修复
改成**流式自适应栅格** + 分档降级：

| 宽度 | 布局 |
|---|---|
| >1360px | 3 指标 + 图表 + 标签 一排 5 列 |
| ≤1360px | 3 指标 + 图表一排，标签换到第二行 |
| ≤1080px | 3 指标一排，图表/标签各占满整行 |
| ≤640px | 2 指标一排 |

配套：数字用 `clamp()` 自适应字号 + `nowrap` 防撑破；图表高度 72→64px；标签限高。

实测 1680 / 1366 / 1200 / 1024px：**同行重叠 0、左右溢出 0、底部溢出 0、
canvas 与容器尺寸完全同步**（Δ=0）；窗口连续缩放 10 档也无失配。

## 四、新闻资讯「科技」分类点击后空白 / 跳转异常

### 原因（根因不在分类，而在详情弹窗）
`<NModal v-model:show="detail">` 把**文章对象**直接绑给了只接受布尔值的 `show`，
Vue 抛 `Invalid prop: type check failed for prop "show". Expected Boolean, got Object`，
弹窗状态不可靠 → 表现为「点了没反应 / 空白 / 像跳到了同一个主页面」。

同一类错误在「空教室 → 存证照片」弹窗也存在（`v-model:show="previewRec"`）。

### 修复
- 拆出独立布尔量 `detailShow` / `previewShow` 控制显隐，关闭时一并清理数据
- 详情请求增加 `id` 校验、竞态保护（请求返回时若已关闭则丢弃）、
  失败时回退显示列表页已有摘要（不再空白），并给出错误提示
- 「在 Edge 中打开原文」按钮在缺少链接时禁用

实测：科技分类 24 张卡片 → 点击打开详情弹窗 → **正文 400 字**，URL 始终停在 `/news`，
无未捕获异常。

## 六、如何构建与覆盖安装

### 一键构建
```powershell
cd "F:\deepseek harness  wenjian"
.\build-all.ps1              # 前端 + 后端 + 安装包 全量构建
.\build-all.ps1 -SkipBackend # 只改前端时用，快很多
```

脚本会依次完成：
1. `vite build` 前端 → 同步到 `polaris-desktop/resources/dist`
2. `PyInstaller` 打包后端 → 同步到 `polaris-desktop/resources/backend`
3. `electron-builder --win` 生成安装包

### 产物位置
| 产物 | 路径 |
|---|---|
| 安装包 | `polaris-desktop/release/北极星个人战略终端 Setup 1.0.0.exe` |
| 免安装版 | `polaris-desktop/release/win-unpacked/` |
| 桌面前端 | `polaris-desktop/resources/dist/` |
| 桌面后端 | `polaris-desktop/resources/backend/polaris-backend.exe` |

### 覆盖已有安装
- **安装包方式**：直接运行新的 `Setup 1.0.0.exe`，会覆盖安装到原目录（用户数据在
  `%APPDATA%` 下的 userData 目录，不受影响）
- **免安装方式**：关掉正在运行的客户端，把 `win-unpacked/` 内容覆盖到原程序目录

### 覆盖前建议
关闭正在运行的「北极星个人战略终端」，否则 exe 被占用会覆盖失败。
